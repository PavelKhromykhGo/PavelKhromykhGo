## 🛒 Мои проекты
- [**URL Shortener**](https://github.com/PavelKhromykhGo/url-shortener) — сервис сокращения ссылок с авторизацией, редиректами, хранением статистики переходов и обкаткой очередей. 
  Реализованы:
  - чистая архитектура (**handler → service → repository**)
  - PostgreSQL
  - REST API
  - логирование (**zap**)
  - метрики (**Prometheus** + **Grafana**)
  - Redis
  - Kafka
  - Docker
- [**fastio**](https://github.com/PavelKhromykhGo/fastio) — Библиотека быстрых ввода/вывода на Go с упором на работу со стандартными потоками и файлами.
- [**workerpool**](https://github.com/PavelKhromykhGo/workerPool) — Небольшая реализация пула воркеров на Go.
- [**Marketplace**](https://github.com/PavelKhromykhGo/marketplace) — backend интернет-магазина с архитектурой **handler → service → repository**, документацией (**Swagger**), логированием (**zap**), мониторингом (**Prometheus**) и тестами (**Testify**).  
- [**To-Do App**](https://github.com/PavelKhromykhGo/go_final_project) — сервис для управления задачами с гибкими правилами повторения.
